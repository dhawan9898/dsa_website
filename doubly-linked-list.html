Each Node Points Both Ways

Doubly Linked List

Every node keeps a pointer to its predecessor as well as its successor, and the list keeps a tail pointer too.

Notes

A doubly linked list adds one thing to a singly linked list: every node also stores a prev pointer back to its predecessor, and the list itself keeps a maintained tail pointer. Those two additions pay for themselves: inserting at the tail becomes O(1) instead of O(n), deleting a node you already have a reference to needs no separate "find the previous node" walk, and you can walk the list backward just as easily as forward — so reaching an arbitrary index can start from whichever end is closer.

The cost is bookkeeping: every insert and delete has to keep two pointers consistent per affected node instead of one, and each node spends a little more memory on the extra pointer.

OperationWhat it doesTime
Insert HeadNew node becomes the headO(1)
Insert TailNew node becomes the tail (tail pointer, no walk)O(1)
Insert / Delete at IndexWalk from whichever end is closerO(n)
SearchWalk from the head comparing valuesO(n)

This is what LinkedList is in most standard libraries (Java's LinkedList, C++'s std::list), and it's the shape behind LRU caches, browser history with both back and forward, and music-player "next/previous track" navigation.
