Backtracking · Try · Recurse · Undo

N‑Queens

Place queens one row at a time; the instant two threaten each other, undo and try the next column — a search that prunes itself as it goes.

Notes

The puzzle: place N queens on an N×N board so that no two attack each other — meaning no two may share a row, a column, or either diagonal. Checking every way to choose N squares out of N² is hopeless even for small boards: on the classic 8×8 board that's C(64,8) ≈ 4.4 billion raw placements to test, and that's before N gets any bigger.

Implementation: the first real insight is structural, not algorithmic — since two queens in the same row always attack each other, a valid board has exactly one queen per row. So instead of choosing squares, the code below chooses one column per row, stored in a plain array col[row]. That alone shrinks the space to NN column assignments. Backtracking is what makes even that fast: solve(row) tries each column left to right, calls isSafe to check it against every queen already placed, and only recurses into solve(row + 1) when it's safe. The moment a column conflicts, the whole subtree of boards built on top of it is skipped without ever being constructed — see Recursion & the Call Stack for the base mechanism this builds on. What makes it backtracking specifically, rather than just recursion, is the line right after the recursive call: col[row] = -1 undoes the placement before trying the next column, so a failed guess never lingers into the next attempt.

ApproachWhat it checksTime
Brute forceEvery way to choose N of the N² squaresfar worse than factorial
One queen per rowEvery column assignment, valid or notO(NN)
Backtracking (this page)Only assignments that stayed safe so farO(N!) worst case, usually far fewer

isSafe(col, row, c) only ever needs to check the rows already placed above it — same column (col[r] == c), or same diagonal, which is true whenever the column distance equals the row distance: abs(col[r] - c) == row - r. Common mistake: dropping the abs() and writing something like col[r] - c == row - r instead. That only catches a queen attacking from the upper-left; one attacking from the upper-right slips through unnoticed, and the algorithm confidently reports a "solution" that quietly has two queens sharing the other diagonal. Both directions need the absolute value, exactly as the code below has it.

Space is just O(N) for the col[] array plus O(N) call-stack depth — one frame per row currently being worked on, which is exactly what the demo below draws next to the board. N-Queens is the standard first example of backtracking precisely because the three moves — try, recurse, undo — are so easy to see acting on a board; the same pattern (choose, recurse, undo) solves Sudoku, graph coloring, and generating subsets or permutations.
