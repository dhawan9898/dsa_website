Data Structures

11 structures

Each one gets notes, a looping demo you can just watch, and an interactive visualizer with Insert/Delete/Search-style buttons that animate exactly what happens underneath.

Stack

Push and pop from one end only — Last In, First Out.

Push/Pop O(1)Search O(n)

Queue

Enqueue at the rear, dequeue from the front — First In, First Out.

Enqueue/Dequeue O(1)

Circular Queue

A fixed-size buffer where front and rear wrap back to index 0.

Enqueue/Dequeue O(1)Fixed capacity

Deque

Insert and delete at either end — front or rear, always O(1).

Both ends O(1)

Singly Linked List

A chain of nodes, each holding a value and a pointer to the next.

Insert Head O(1)Search O(n)

Doubly Linked List

Every node points both ways, and a tail pointer is kept too.

Head/Tail O(1)Search O(n)

Binary Search Tree

Left is always smaller, right is always larger, at every node.

Avg O(log n)Worst O(n)

AVL Tree

A self-balancing BST that rotates after every change — never O(n).

Guaranteed O(log n)

Priority Queue

A binary heap — the highest-priority value always sits at the root.

Insert/Extract O(log n)Peek O(1)

Hash Table

Hash a key straight to a bucket index; collisions chain together.

Avg O(1)Worst O(n)

Graph

Vertices and edges, explored with breadth-first or depth-first search.

Traverse O(V + E)

Sorting

8 algorithms

Each comparison, swap, and write happens on screen, in order, with a running log underneath — press Play or step through by hand.

Bubble Sort

Swap out-of-order neighbours, over and over, until a full pass makes no swaps.

Avg O(n²)Space O(1)Stable

Selection Sort

Scan the unsorted remainder for its smallest value, then swap it to the front.

Avg O(n²)Space O(1)Not stable

Insertion Sort

Grow a sorted prefix one value at a time, walking each new value left into place.

Avg O(n²)Space O(1)Stable

Merge Sort

Split the array in half recursively, then zip each pair of sorted halves back together.

Avg O(n log n)Space O(n)Stable

Quick Sort

Pick a pivot, partition everything else around it, then recurse on each side.

Avg O(n log n)Space O(log n)Not stable

Heap Sort

Arrange the array into a max-heap, then repeatedly pull the largest value from the root.

Avg O(n log n)Space O(1)Not stable

Shell Sort

Insertion sort with far-apart comparisons first, shrinking the gap down to 1.

Avg O(n¹·³≈)Space O(1)Not stable

Counting Sort

Count each value's occurrences, accumulate positions, then place every value directly.

Avg O(n + k)Space O(n + k)Stable

Searching

3 algorithms

Give it an array and a target value, then watch how each strategy narrows down where that value could be.

Linear Search

Check every index in order until the target turns up. Needs no particular ordering.

Avg O(n)Space O(1)Any order

Binary Search

Compare against the middle of the range and discard the half that can't contain it.

Avg O(log n)Space O(1)Needs sorted

Jump Search

Leap forward in fixed-size blocks, then scan the one block the target must be in.

Avg O(√n)Space O(1)Needs sorted
