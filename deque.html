Double-Ended Queue

Deque

A queue with both ends open for business — insert and delete at the front or the rear.

Notes

A deque ("deck", short for double-ended queue) generalizes both the stack and the queue: it supports inserting and deleting at both ends, each in O(1). Use only the rear for insertion and the front for removal and it behaves exactly like a queue; use only one end for both and it behaves exactly like a stack.

Real implementations back a deque with a doubly linked list, or a resizable circular buffer — never a plain array, since inserting at the front of a plain array would mean shifting every other element down.

OperationWhat it doesTime
Insert FrontAdd a value at the frontO(1)
Insert RearAdd a value at the rearO(1)
Delete FrontRemove the front valueO(1)
Delete RearRemove the rear valueO(1)

Sliding-window algorithms (like the classic "maximum in every window of size k") are the textbook use case: values get added at the rear and dropped from either end as the window slides. Browser history and undo/redo stacks that also support "redo forward" reach for the same shape.
