Last In · First Out

Stack

A collection where you can only ever add to, or remove from, one end — the top.

Notes

A stack holds items in the order they arrived and only exposes one end for both adding and removing: the top. That single rule — Last In, First Out (LIFO) — is the entire definition. There's no reaching into the middle, and no peeking at the bottom.

Because every operation only ever touches the top element, a stack never needs to shift or search anything: push and pop are both O(1), whether the stack holds 3 items or 3 million.

OperationWhat it doesTime
PushAdd a value on topO(1)
PopRemove and return the top valueO(1)
Peek / TopLook at the top value without removing itO(1)
SearchFind a value anywhere in the stackO(n)

Used constantly under the hood: every function call your program makes is pushed onto a call stack, and returning from it is a pop. Undo/redo history, "back" buttons, matching brackets, and depth-first search all lean on the same LIFO idea.
