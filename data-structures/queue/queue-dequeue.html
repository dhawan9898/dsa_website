Leave From The Front · Or Just Look

Dequeue & Peek

Dequeue serves the person at the front and moves the line up; peek just checks who's next.

Overview Enqueue Dequeue & Peek Playground

Dequeue: take from the front

O(1)

Dequeue removes the value at the front — the one that has waited longest — and returns it. It reads that slot, then moves front one step to the right so the next person becomes the new front.

  1. Check it isn't empty. If front == -1, there's nobody in line — stop.
  2. Read and advance. Take items[front], then front++ steps the front index forward.
  3. Reset if drained. If front has now passed rear, the queue is empty again — set both back to -1 for a clean start.

 

Watch the dead space. Notice the slot the departed front left behind (dimmed). front never moves back, so a plain array queue can't reuse it — the flaw the Circular Queue exists to fix.

Peek: look without removing

O(1)

Peek (also "front") returns items[front] but changes nothing — no index moves. It's how you check who's next without pulling them out of line.
