What enqueue has to do

Enqueue adds a new value at the back of the line. A queue keeps two indices — front (where the next person leaves) and rear (the last filled slot). New values always land just past rear, so enqueue is the mirror of a stack's push, just at the other tracked end.

  1. Check for room. If rear is already at the last slot (MAX - 1), there's no space at the back — stop. (Even if the front has freed slots, a plain array queue can't reach back to them; that's the dead-space problem the overview describes.)
  2. Move rear up and write. ++rear steps the back index forward, and the value is stored at items[rear].
  3. Handle the first item. If the queue had been empty (front == -1), point front at index 0 too, so there's a valid front to dequeue from.
O(1). One index step, one write, no shifting — enqueue costs the same whether the queue holds one item or a thousand.
