The idea, in one picture

Picture the line at a coffee shop. New people join at the rear. The person at the front — who has waited longest — gets served and leaves next. Nobody cuts in, and nobody is served out of order. A queue is exactly this: a collection where you add at one end and remove from the other.

That rule is called First In, First Out, or FIFO — the exact mirror of a stack's LIFO. A stack touches one end for everything; a queue uses two ends, one to join and one to leave, so things come out in the same order they went in.

Three moves. Enqueue = add a value at the rear. Dequeue = remove (and return) the front value. Peek = look at the front value without removing it. Each gets its own page below.

How it works

an array + two indices

Take an array and keep two indices instead of a stack's one: front (the slot to leave from) and rear (the last slot filled). Enqueue writes at ++rear; dequeue reads at front++. Each touches one index and one slot — no shifting — so both are O(1). Watch both indices move:

The catch: dead space

why this simple version wastes room

Dequeue moves front to the right but never reclaims the slot it left behind. After a few dequeues, the far-left slots sit occupied by old, dead values the queue can never reuse — because front only ever moves forward. So when rear reaches the last slot, this array queue reports itself full even if half the slots at the front are free.

This flaw is the whole reason the next structure exists. The Circular Queue fixes it by letting the indices wrap around to index 0 when they hit the end, reusing the freed front slots. The other common fix is a linked list with front and rear node pointers — no fixed capacity, no dead space.

The one gotcha. A naive "fix" for dead space is to shift every remaining element one slot left after each dequeue. Don't — that turns O(1) dequeue into O(n). Wrap the indices (circular) or use linked nodes instead.

Where you'll meet queues. Anywhere work must be handled in arrival order: print spoolers, task and job schedulers, message queues between services, keyboard input buffers, and breadth-first search, which explores a graph in the exact order it discovers nodes.
