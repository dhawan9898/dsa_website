Enqueue and dequeue each touch only one end, so both are O(1) — no shifting. But notice the flaw: once rear reaches the last slot, this queue is "full" even if dequeues have freed slots at the front. Those slots are dead space. The Circular Queue fixes exactly this by wrapping the indices around.
