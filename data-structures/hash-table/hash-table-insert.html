Insert

Two moves: compute the bucket from the key, then push a node onto that bucket's chain.

Overview Insert Search & Delete Playground

What insert has to do

Insert stores a key by first turning it into a bucket index, then adding it to that bucket's chain. Because the index comes from arithmetic (not a search) and the add is a linked-list prepend, the whole thing is O(1).

  1. Hash the key. i = key % M gives a bucket index in 0 … M-1.
  2. Make a node for the key.
  3. Prepend it. Point the new node's next at the bucket's current chain head, then point the bucket at the new node. It's now the head of that chain.
Collisions are a non-event. If the bucket already holds keys, the new one just becomes the new head of the same chain — no special case, no slowdown for the insert itself. The chain simply gets one longer.
