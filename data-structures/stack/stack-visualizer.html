Every operation only ever touches the top index — never the middle — which is what makes push and pop O(1) no matter how tall the stack is. Push past the last slot is a stack overflow; pop when top == -1 is an underflow. Function call stacks, undo history, and browser "back" buttons are all real-world stacks.
