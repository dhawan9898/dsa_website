Add A Value On Top

Push

The fastest operation a stack has: no walking, no shifting — bump one index and write one slot.

Overview Push Pop & Peek Playground

What push has to do

Pushing means putting a new value on top of the stack. Because a stack only ever grows at one end, the new value always lands just above the current top — there's nowhere else it could go. The stack is an array plus an index called top that marks the highest filled slot, so "on top" means "one slot past top."

The whole operation is two moves. Move top up by one, then write the value into that slot. There's no searching and nothing to shift, so push takes the same tiny amount of time whether the stack holds 1 item or a million — that's what O(1) means.
  1. Check for room. If top is already at the last slot (MAX - 1), the array is full — pushing would run off the end. Stop here; that overflow is covered below.
  2. Move top up. ++top increases the index by one so it points at the next empty slot.
  3. Write the value. Store the new value at items[top]. Done — it's the new top.

Reading the C

  • if (s->top == MAX - 1) return; — the full check. s->top reads the top field of the stack this pointer refers to (the -> arrow is explained on the Pointers page). If there's no room, bail out.
  • s->items[++s->top] = val; — ++s->top bumps the index up first, and the result is used to pick the slot, so the value lands in the newly opened slot. One line does the move and the write together.
When it breaks: stack overflow. An array-backed stack has a fixed capacity. Push past the last slot and, without the guard, you'd write outside the array — corrupting memory. That guard is why the push above refuses once the stack is full. The term comes from the real call stack overflowing when recursion never stops.
