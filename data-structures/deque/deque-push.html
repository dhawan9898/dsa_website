Add At Either End

Push (front & rear)

Two directions, same wrapping array: rear moves forward, front moves backward — both with % MAX.

Overview Push (both ends) Pop (both ends) Playground

Push rear: add on the right

O(1)

Pushing at the rear is identical to a circular queue's enqueue: the next free slot on the right is (front + size) % MAX. Write there and grow size.

  1. Compute the write index i = (front + size) % MAX.
  2. Store the value at items[i], then size++.

 

Push front: add on the left

O(1)

This is the move a plain queue can't make. To add at the left, the front index steps backward by one — and because it might fall below 0, the wrap uses (front - 1 + MAX) % MAX. The + MAX keeps the number non-negative before the % takes the remainder, so front-of-0 wraps neatly to the last slot.

  1. Step the front back: front = (front - 1 + MAX) % MAX.
  2. Write the value at the new items[front], then size++.

 

Why + MAX? In C, a negative index modulo a positive number can come out negative, which would point outside the array. Adding MAX first guarantees a non-negative value, so the wrap always lands in 0…MAX-1.
