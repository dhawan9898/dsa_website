    Both BFS and DFS visit every vertex reachable from the start exactly once, in O(V + E) time — the difference is purely order. BFS uses a queue and spreads outward level by level (shortest path in an unweighted graph); DFS uses a stack (or recursion) and commits to one path as deep as it goes before backtracking.
