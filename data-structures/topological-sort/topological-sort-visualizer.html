    Every vertex enters the queue exactly once and every edge is examined exactly once, so Kahn's algorithm runs in O(V + E). If the graph has a cycle, every vertex in that cycle keeps at least one prerequisite forever, so the queue empties with vertices left unordered — that's the standard way to detect a cycle in a directed graph.
