The Code

recursive AVL insert with the four rotation cases
Each insert still walks one path down (O(log n)); the extra work is checking the balance factor on the way back up and doing at most one rotation, which is O(1). So AVL keeps every operation O(log n) — guaranteed, whatever order the keys arrive in.
