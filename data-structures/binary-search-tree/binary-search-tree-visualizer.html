Search, insert, and delete all follow one root-to-leaf path, so each is O(h) — the height of the tree. Keep the tree balanced and h ≈ log n, giving O(log n); let it grow into a lopsided chain and h ≈ n, giving O(n). That "keep it balanced" problem is exactly what the AVL tree solves.
