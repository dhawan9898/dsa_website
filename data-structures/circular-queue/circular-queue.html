The Queue That Wraps Around

Circular Queue

A queue that reuses its own freed slots by letting the indices loop back to the start — no dead space, ever.

Overview Enqueue Dequeue & Peek Playground

The problem it solves

Start on the Queue page if you haven't — this structure exists to fix one specific flaw there. A plain array queue moves front to the right on every dequeue and never looks back, so the freed slots at the left become dead space. Eventually rear hits the last slot and the queue calls itself "full" even though half of it is empty.

The fix is almost embarrassingly simple: when an index reaches the end of the array, let it wrap around to index 0 instead of stopping. The array stops being a straight line and behaves like a ring — hence "circular." Now those freed front slots sit right in front of rear again, ready to reuse.

How the wrap works

one operator does everything: % MAX

The whole trick is the modulo operator, % — the remainder after division. For an array of size MAX, index % MAX counts 0, 1, …, MAX-1, 0, 1, … and can never fall off the end, because right after MAX-1 it snaps back to 0. That single expression turns a line into a ring. Telling full from empty

why we keep a size counter

Wrapping creates one subtle puzzle. front and rear can point at the same place in two different situations: when the queue is completely empty, and when it is completely full and has wrapped all the way around. The indices alone can't tell you which.

Two standard ways out. The simplest, used here, keeps a separate size counter: size == 0 is empty, size == MAX is full, no ambiguity. The other common trick deliberately leaves one slot always empty. The size counter is easier to read.

Going deeper

costs and where ring buffers show up

EnqueueWrite at (front+size)%MAX, size++O(1)
DequeueRead front, advance with wrap, size--O(1)
Peek / FrontLook at items[front]O(1)

Every operation is still O(1) — the wrap costs nothing, it's just one %. What you gain over the linear queue is full use of a fixed block of memory: no dead space, no growing, no shifting.

Where you'll meet circular buffers. Audio and video streaming buffers, keyboard and network input buffers, the ring buffers inside operating-system drivers, and any producer/consumer setup where one side fills the buffer while the other drains it. When you hear "ring buffer," this is it.
