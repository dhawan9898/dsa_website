Circular Queue

A fixed-size buffer that treats its last index and its first index as neighbours.

Notes

A plain array-backed queue has a problem: after enough enqueues and dequeues, the front pointer creeps rightward and the slots behind it just sit there wasted, unusable, even though the queue isn't full. A circular queue fixes this by wrapping front and rear back to index 0 with a modulo ((i + 1) % capacity) once they reach the last slot — the array behaves like a ring instead of a dead-ending line.

The trade-off is a fixed capacity, decided up front, and a little index arithmetic on every operation to detect "full" versus "empty" (both can otherwise look identical: front equals rear).

OperationWhat it doesTime
EnqueuePlace a value one slot past rear, wrapping if neededO(1)
DequeueRemove the value at front, wrapping if neededO(1)
Peek / FrontLook at the front value without removing itO(1)

This is the shape behind ring buffers used in streaming audio/video pipelines, keyboard input buffers, and fixed-size producer/consumer queues where capacity is deliberately capped.
