What enqueue has to do

Enqueue adds a value at the back. The one difference from a plain queue is how it finds "the back": instead of a rear index that marches off the end, it computes the next free slot as (front + size) % MAX. That expression is front plus however many items are already stored, wrapped around the array's length — so it always lands on the first free slot, even if that means looping back to index 0.

  1. Check for room. If size == MAX, every slot holds a live item — the queue is full, stop.
  2. Compute the wrapped write index i = (front + size) % MAX. When front + size reaches or passes MAX, the % snaps it back into the range 0…MAX-1 — that's the wrap.
  3. Write and grow. Store the value at items[i], then size++.
The wrap is the whole point. Because the index is computed with % MAX every time, slots freed by earlier dequeues get reused automatically — no dead space, and still O(1).
