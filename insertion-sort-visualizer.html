Insertion Sort

Builds a sorted prefix one element at a time. Each new value walks left past everything bigger than it until it finds its place.

Running commentary

Load an array to begin.

    Insertion sort shines on data that's already close to sorted — a nearly-sorted array means each key only has to shift a step or two before it finds its place, which is why it's often used to finish off small partitions inside faster sorts like quicksort.
