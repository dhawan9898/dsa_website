Bubble Sort

The simplest sort there is: walk the array, swap any neighbours that are out of order, and repeat until a full pass makes no swaps.

Notes

Bubble sort makes repeated passes over the array. On each pass it walks left to right, comparing every pair of neighbours and swapping them if they're out of order. One full pass guarantees the largest remaining value has "bubbled" all the way up to its correct resting place at the end — which is why the sorted region grows from the right, one element per pass.

CaseComparisonsTime
Worst / average~n²/2O(n²)
Best (already sorted)n−1O(n)
SpaceO(1) — sorts in place

Implementation: the code panel below carries a swapped flag that's the whole reason the best case is O(n) rather than O(n²): if an entire pass completes with no swaps, the array was already sorted, and the algorithm exits immediately instead of grinding through the remaining passes anyway. The inner loop's bound, n - 1 - i, also shrinks by one every pass — it never re-compares the suffix that's already provably sorted.

Common mistake: drop the swapped flag (or the shrinking inner bound) and bubble sort still produces a correct answer — it just silently pays the full O(n²) cost every single time, even on an array that was already sorted. Because the result is still correct, this kind of bug never shows up as a wrong answer, only as a slowdown nobody notices until the input gets large.
